# VINIVIDIVICI

Brand website with three worlds: VINI (audiovisual studio), VIDI (shop, cash on delivery), VICI (coming soon).

## Repository layout
- `backend/`: FastAPI API, worker, migrations, tests
- `frontend/`: Next app (public site + admin)
- `contract/`: `openapi.json`, the API contract generated from the backend
- `docs/decisions/`: architecture decision records (ADRs)
